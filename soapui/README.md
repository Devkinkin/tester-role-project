# SoapUI – Week 2 Setup Notes

Goal: create a simple REST smoke test once the group's API endpoint is confirmed.

1. Open SoapUI.
2. Create a new REST Project.
3. Enter a real endpoint from the group application.
4. Add a GET request.
5. Add a Valid HTTP Status Codes assertion (e.g. 200).
6. Add a response-content assertion if the API returns a known field.
7. Save the SoapUI project XML into this folder.

Do not claim an API passed until the real endpoint has been executed.
