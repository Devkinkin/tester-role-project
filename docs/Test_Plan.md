# Starter Test Plan

## Objective
Provide repeatable baseline testing for the group's .NET web application.

## Scope for first two weeks
- Smoke testing
- Basic functional testing
- Compatibility/usability checks
- Starter Selenium automation
- Starter API testing with Postman
- Starter performance testing with JMeter
- Defect reporting process

## Test approach
1. Run smoke tests on each usable build.
2. Record defects with exact steps, expected result and actual result.
3. Re-test fixed defects.
4. Run regression checks on previously working areas.
5. Add automation only for stable, repeatable scenarios.

## Exit criteria for the starter phase
- Baseline test cases documented.
- Selenium project runs against a configured base URL.
- Postman collection created.
- JMeter starter plan created.
- Defect template agreed with the team.
